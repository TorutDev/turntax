turntax

Coding agents re-send their instruction files (CLAUDE.md, AGENTS.md, Cursor, Copilot and Windsurf rules) with every turn. Drop a repository folder to see that per-turn token cost for tools, and where to cut it.

Runs entirely in your browser with the offline o200k tokenizer. Nothing is uploaded.

What your agent instructions cost on every turn

Coding agents re-send their instruction files with every message. turntax applies each agent's documented loading rules, measures what is sent every turn, and shows what to trim.

npx turntax
    Drop a repository folder

    Only agent instruction files are read. node_modules, .git and build folders are skipped.

    Loading a repository downloads its files from api.github.com and raw.githubusercontent.com. Nothing is uploaded.
